# Android publication preparation (experimental)

In Settings choose Indonesian and English, select HY-MT2, and tap Update reference library. Confirm the download. The app obtains public EPUB metadata from the publisher and downloads both languages if the cached pair has changed. It attempts alignment using exact chapter basename and paragraph ID, not positional guessing. It keeps validated pairs in app-private, no-backup storage, builds a bounded offline corpus, and retains prior pairs when new downloads fail. Imported glossaries are separate. Clear reference material removes both. No copyrighted files are shipped. The no-network verification builds retain their permission restrictions.

Limitations: only the Indonesian/English pair is mapped, issue candidates are calendar heuristics, multiple-edition files and irregular Awake/Public Watchtower issues are not resolved, and EPUB IDs are not proof of translation equivalence. Long paragraphs and nonmatching IDs are skipped. The index is bounded at 8 MiB/30,000 rows per active imported or downloaded corpus. No ASR biasing or scheduled background work yet. Updates can take time; run the first on Wi-Fi. The live API response and Android build/inference have not been verified. Do not treat this as a release-ready implementation. See PUBLICATION_SYNC.md for the independent downloader.
